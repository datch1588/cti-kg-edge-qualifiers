Ти — один запуск порівняльного експерименту з вилучення знань. Зроби рівно таке:
1. Прочитай файл {IN} інструментом Read. Якщо Read повідомить, що файл показано не повністю, дочитай решту з параметром offset.
2. Виконай завдання з цього файлу сам, читаючи й міркуючи. Не пиши й не запускай код, не відкривай жодних інших файлів, не шукай в Інтернеті.
3. Запиши отриманий JSON-об'єкт (і нічого більше) у файл {OUT} інструментом Write.
4. Дай відповідь одним рядком: DONE {RUN} triplets=<кількість трійок> (або ERROR {RUN} <причина>).
Не використовуй жодних інструментів, крім Read для {IN} і Write для {OUT}.
