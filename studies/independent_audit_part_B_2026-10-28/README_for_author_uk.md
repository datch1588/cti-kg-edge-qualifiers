# Як запустити незалежний аудит правил 8а

Потрібна модель іншої родини, не Claude. Найпростіше взяти ту саму, що 28.10 (GPT‑6 Astra Pro, той самий режим): тоді обидва незалежні аудити статті виконано однією моделлю. Найбільший файл, N08, має близько 39 тис. символів.

1. Запишіть у файл `vidpovidi/MODEL.txt` точну назву й версію моделі, сервіс, режим і дату.
2. Для кожного файлу `dlia_audytora/N01.txt` … `N10.txt`:
   - відкрийте **новий** чат; вимкніть пам'ять, власні інструкції, пошук в Інтернеті та інші інструменти;
   - вставте текст із `dlia_audytora/ZAPYT.txt`, а під ним увесь вміст файлу N##.txt (або прикріпіть файл, якщо сервіс читає його повністю);
   - збережіть відповідь моделі як `vidpovidi/N##.json` (з тим самим номером);
   - перевірте, що у відповіді є останній номер запису, указаний в останньому рядку файлу (наприклад, `N01-E061`). Якщо відповідь обірвалась, повторіть цей файл у новому чаті один раз.
3. Надішліть файли з `vidpovidi/` у тред статті. Аналіз зробить `scripts/analyze_independent_v3.py`.

Усі файли для аудитора разом: `Fayly_dlia_audytora_N01-N10.zip` (N01–N10, `ZAPYT.txt`, `shablon_vidpovidi.json`).

Можна запустити лише частину файлів: скрипт рахує за тими, що є, і показує покриття. Для висновку протокол вимагає не менше 90 % записів.

**Не передавайте моделі** папку `keys/`, протоколи, скрипти чи будь-які файли з папок дослідів: там назви систем і вердикти основного аудиту. Моделі потрібні лише `ZAPYT.txt` і файли `N##.txt`.

Кількість записів у файлах: N01 — 61, N02 — 58, N03 — 57, N04 — 55, N05 — 52, N06 — 61, N07 — 61, N08 — 61, N09 — 61, N10 — 57 (разом 584).
