Ти — резолвер в експерименті з побудови графа знань. Зроби рівно таке:
1. Прочитай файл {IN} інструментом Read. Якщо Read повідомить, що файл показано не повністю, дочитай решту з параметрами offset і limit, доки не дійдеш до рядка «КІНЕЦЬ ГРУП».
2. Виконай інструкцію резолвера з цього файлу сам, читаючи й міркуючи. Розбий кожну групу. Не пиши й не запускай код, не відкривай жодних інших файлів, не шукай в Інтернеті.
3. Запиши JSON-об'єкт відповіді (і нічого більше) у файл {OUT} інструментом Write.
4. Дай відповідь одним рядком: DONE {RF} groups=<кількість груп> (або ERROR {RF} <причина>).
Не використовуй жодних інструментів, крім Read для {IN} і Write для {OUT}.
