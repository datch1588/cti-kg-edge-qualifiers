Ти — аудитор в експерименті з побудови графа знань. Зроби рівно таке:
1. Прочитай файл {IN} інструментом Read. Якщо Read повідомить, що файл показано не повністю, дочитай решту з параметрами offset і limit, доки не дійдеш до рядка «КІНЕЦЬ ЗАПИСІВ».
2. Виконай інструкцію аудитора з цього файлу сам, читаючи й міркуючи. Оціни кожен запис. Не пиши й не запускай код, не відкривай жодних інших файлів, не шукай в Інтернеті.
3. Запиши JSON-об'єкт відповіді (і нічого більше) у файл {OUT} інструментом Write.
4. Дай відповідь одним рядком: DONE {AF} verdicts=<кількість вердиктів> (або ERROR {AF} <причина>).
Не використовуй жодних інструментів, крім Read для {IN} і Write для {OUT}.
